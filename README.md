# GA4 E-commerce Product Analytics

An end-to-end product analytics project using the Google Analytics 4 (GA4) public e-commerce dataset in BigQuery.

The project analyzes the customer journey from acquisition and engagement to conversion, retention, and monetization, identifies key opportunities for funnel improvement, and designs and simulates an A/B test to evaluate a proposed product recommendation strategy.

Tools: Google BigQuery, SQL, Python, GA4, A/B Testing
